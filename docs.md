# SailPoint Identity Security

## Overview

:::caution Looking for Identity Security Cloud?

You're in the right place. Identity Security Cloud is now SailPoint Identity Security. SailPoint Identity Security includes SailPoint Human Fabric, for human identities, and SailPoint Agentic Fabric, for AI agent security.

:::

SailPoint Identity Security is a unified, multi-tenant identity governance and security platform. SailPoint Identity Security provides organizations with the ability to ensure that their users, known as identities, have secure access to different data sources, and it makes identity access management fast and easy.

SailPoint Identity Security out of the box will often meet all your identity governance and security needs, but it's possible that it won't. The beauty of the platform is that even if it doesn't quite meet all your needs, you can extend the platform's functionality and build custom solutions that do!

The SailPoint Developer Documentation provides developers with all the information they need to extend their platforms' functionality and build their desired solutions. The developer documentation is written for developers of all experience levels, from nontechnical users exploring what's possible to advanced developers who live and breathe code.

Check out the developer documentation and see what's possible!

:::info Are you a partner?

The developer documentation is written for customers and partners who already have access to SailPoint Identity Security. If you're interested in becoming a partner, go [here](https://www.sailpoint.com/partners/become-partner/).

:::
