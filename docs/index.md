## Overview

:::caution Looking for IdentityNow or Identity Security Cloud?

You're in the right place. This platform was previously named IdentityNow, then Identity Security Cloud (ISC). It is now SailPoint Human Fabric (SHF). The product is the same — only the name has changed.

:::

SailPoint Human Fabric (SHF) is a unified, multi-tenant identity governance and security platform. SHF provides organizations with the ability to ensure that their users, known as identities in SHF, have secure access to different data sources, and it makes identity access management fast and easy.

The SHF platform out of the box will often meet all your identity governance and security needs, but it's possible that it won't. The beauty of SHF is that even if it doesn't quite meet all your needs, you can extend the platform's functionality and build custom solutions that do!

The SailPoint Developer Documentation provides developers with all the information they need to extend their platforms' functionality and build their desired solutions. The developer documentation is written for developers of all experience levels, from nontechnical users exploring what's possible to advanced developers who live and breathe code.

Check out the developer documentation and see what's possible!

:::info Are you a partner?

The developer documentation is written for customers and partners who already have access to SHF. If you're interested in becoming a partner, go [here](https://www.sailpoint.com/partners/become-partner/).

:::
