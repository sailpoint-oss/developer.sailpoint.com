create-source-subtype-override-v2​

experimental

This API is currently in an experimental state. The API is subject to change based on feedback and further testing. You must include the X-SailPoint-Experimental header and set it to true to use this endpoint.

Create a source subtype that overrides a connector subtype on one source. The new source subtype copies the connector subtype's machine account configuration and provisioning policy at the time of the request. Later changes to the connector subtype are not applied to the override.

The subtype identified by id must be a CONNECTOR subtype (otherwise 400) that is in the source's effective subtypes. An unknown subtype or source returns 404. The request is rejected if the tenant's subtype configuration cannot be changed this way.

The caller needs the idn:source-subtypes:create right, held by org admins, source admins and source sub-admins. A caller without it receives 404, not 403. A malformed ID returns 400.

This API returns 404 when Machine Identity Security or tiered subtype configuration is not enabled for the tenant.
