# MetricType

Enum representing the currently supported metric aggregation types. Additional values may be added in the future without notice.

## Enum

* `COUNT` (value: `'COUNT'`)

* `UNIQUE_COUNT` (value: `'UNIQUE_COUNT'`)

* `AVG` (value: `'AVG'`)

* `SUM` (value: `'SUM'`)

* `MEDIAN` (value: `'MEDIAN'`)

* `MIN` (value: `'MIN'`)

* `MAX` (value: `'MAX'`)
