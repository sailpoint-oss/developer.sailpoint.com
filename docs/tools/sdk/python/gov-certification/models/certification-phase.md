# CertificationPhase

The current phase of the certification. * `STAGED`: The certification is waiting to be activated. * `ACTIVE`: The certification is active. * `SIGNED`: The reviewer has signed off on the certification, and it is considered complete. 

## Enum

* `STAGED` (value: `'STAGED'`)

* `ACTIVE` (value: `'ACTIVE'`)

* `SIGNED` (value: `'SIGNED'`)
