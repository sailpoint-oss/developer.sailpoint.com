Override source connector subtype Create a source subtype that overrides a connector subtype on one source. The new source subtype copies the connector subtype's machine account configuration and provisioning policy at the time of the request. Later changes to the connector subtype are not applied to the override.

The subtype identified by id must be a CONNECTOR subtype (otherwise 400) that is in the source's effective subtypes. An unknown subtype or source returns 404. The request is rejected if the tenant's subtype configuration cannot be changed this way.

The caller needs the idn:source-subtypes:create right, held by org admins, source admins and source sub-admins. A caller without it receives 404, not 403. A malformed ID returns 400.

This API returns 404 when Machine Identity Security or tiered subtype configuration is not enabled for the tenant.

Create subtype provisioning policy Create the machine account creation provisioning policy of a subtype of any tier. A subtype has at most one provisioning policy; the request is rejected if one already exists.

id and subtypeId must not be supplied (otherwise 400). usageType must be CREATE_MACHINE_ACCOUNT or omitted. name defaults to the subtype's display name.

Who can call this API depends on the tier of the subtype:

  • SOURCE: requires the idn:source-subtypes:update right, held by org admins, source admins and source sub-admins.

  • CONNECTOR: requires the idn:connector-subtypes:update right, held by org admins.

A caller without the right for the subtype's tier receives 404, not 403. A malformed ID returns 400.

This API returns 404 when Machine Identity Security or tiered subtype configuration is not enabled for the tenant.
