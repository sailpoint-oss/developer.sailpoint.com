# Track 04 · MCP Server

Trade the UI for a conversation. You will pick your preferred programming language, get the SailPoint
MCP server template running from the matching repository, and then build your own tools on top of it.

## How to get started

Work through the steps in order. This guide gets you up and running with the essentials, and you'll expand from there.

### 1. Clone the template

Choose your preferred language and clone that repository.

<Tabs>
  <TabItem value="python" label="Python" default>

```bash
git clone git@github.com:sailpoint-oss/python-mcp-server-template.git
```

  </TabItem>
  <TabItem value="typescript" label="TypeScript">

```bash
git clone git@github.com:sailpoint-oss/typescript-mcp-server-template.git
```

  </TabItem>
  <TabItem value="golang" label="GoLang">

```bash
git clone git@github.com:sailpoint-oss/golang-mcp-server-template.git
```

  </TabItem>
</Tabs>

Here's what comes out of the box to get you started:

- Authentication to SailPoint handled via personal access token and the SDK
- A foundational MCP server with copyable tool templates

### 2. Pick your AI client

The examples in each repository use Claude as their example client for interacting with the MCP
server. You can use any AI client that supports MCP connections.

### 3. Create your credentials

When you registered for Hack Day you should have received a demo tenant. Log in to the tenant and
generate a personal access token with `sp:scopes:all`, then save the credentials for the next step.

See [Generating a personal access token](https://documentation.sailpoint.com/saas/help/common/api_keys.html#generating-a-personal-access-token)
for the full walkthrough.

### 5. Make an example call

Open your AI client and make an example call — try asking something like "Tell me more about the
identity Adam Archer."

Watch the Search Identities tool get called on the template MCP server. The JSON it returns goes back
to the AI client, which turns it into a readable answer.

### 6. Build

Now that you have the full picture, build a tool or a set of tools that solves a real-world problem.
What you build should:

- Leverage SailPoint APIs to provide actionable insights or data
- Be small, self-contained, and functional
- Demonstrate a clear and intentional use case
